강남언니 상담 문의 5배 증대

COMPANY 네오커스 TAG Landing · CRO · Keyword
● ×5 문의

'병원이 쓰는 단어' 를 '유저가 검색하는 단어' 로

PROBLEM · 문제 인식
  • 동일 시술 경쟁 병원은 월 상담 50건+, 우리 병원은 6~8건 미만 (경쟁사의 10~15% 수준)
  • 내부 반응: "광고비를 안 써서 안 되는 것"
  • 실제 원인: 2024년 이후 이벤트 페이지·썸네일 수정 이력 없음
  • 병원 내부 네이밍('뺏주사') 중심 · 시술 설명 위주 랜딩 구조 → 설득 실패 + 클릭 유도 실패
HYPOTHESIS · 가설
  • 강남언니 유저는 시술을 이미 확정하고 병원만 고르는 고관여 타겟
  • 이들에게 필요한 건 시술 정보가 아니라 "이 병원이 효과적이다" 라는 확신
  • '뺏주사'는 고객친화적이지 않음 — 실제 검색어는 '지방분해' 가 아닐까
  • 기존 이미지의 미 기준이 올드함 — 최근 트렌드는 가슴 부각이 아니라 건강미
BEFORE · 병원 언어

02

대만 Meta 머신러닝 학습 개선

COMPANY 네오커스 REGION Taiwan TAG ML · Lookalike · Dwell
● 46s → 1:24

체류시간이 짧다 = 머신러닝이 엉뚱한 유저를 학습한다

PROBLEM · 문제 인식
  • 대만 Meta 첫 집행 후 트래픽은 급증, 전환(WeChat 문의)은 0
  • 평균 체류시간 1분 24초 → 46초 급감
  • 트래픽 + 전환 캠페인 병행 운영, 동일 픽셀 이벤트 학습
  • → 저관여 클릭 유저까지 전환 신호로 학습되며 머신러닝이 이탈 유저를 정상 유저로 인식
  • Meta 측 답변: "대만 트래픽은 소모성 클릭이 많다" → 가짜 전환이 쌓이는 환경
HYPOTHESIS · 가설
  • 대만은 저관여 클릭이 아니라 "실수 클릭" 이 많다
  • 트래픽 증가 ≠ 성과. 고관여 유저가 유입되어야 문의가 발생하는 업종 특성
  • 광고 성과가 아니라, 머신러닝이 어떤 데이터를 학습하고 있는지 로 문제를 재정의
  • 전환 기준을 '행동' 이 아니라 '관여도' 로 재설계해야 한다
INITIAL RESPONSE · 초기 대응
  • 트래픽 광고 중단 → 전환 캠페인만 유지했지만 문의 개선 없음
  • → 단순 유입 조절이 아니라 학습 데이터 자체의 문제 로 확정
CORE FIX · 핵심 수정
BEFORE
  • 단순 클릭/방문 기준 전환
  • 전체 유입 기반 맞춤 타겟
  • 저관여 포함 학습 데이터
AFTER
  • 스크롤 25% + 체류시간 조건
  • 고관여 유저만 맞춤 타겟
  • 유사 타겟(LAL) 단계적 확장

PROBLEM · 문제 인식
  • 이전 직장에서 틱톡·구글 영상광고를 먼저 경험 — "영상광고가 정적이면 안 된다" 를 체감
  • 이 케이스에서는 소재가 정적 이미지 기반, 디자인이 플랫폼 분위기와 불일치
  • 타겟과 맞지 않는 샤방샤방 · 글로시한 소재 → TikTok 환경에 비친화적
  • 디자인팀과 협업 시 마케터·디자이너의 언어 차이 발견 — 마케터는 카피/메시지, 디자이너는 컬러/비주얼을 먼저 본다
  • 알고리즘 작동 방식과 소재 변경 필요성을 데이터로 설명 하며 우선순위를 맞춰나감
HYPOTHESIS · 가설
  • TikTok 유저는 빠르게 넘기고, 사운드에 반응하며, 정보를 다 주면 오히려 이탈
  • 호기심을 유발하고 타겟이 "나 얘기네" 라고 느끼는 포맷이어야 한다
  • → 매체마다 맞는 소재와 랜딩 이 따로 있다
